# CineGram: отдельные приложения

Каждый пользователь устанавливает приложение и запускает встроенный сервер на своём устройстве. Хостинг, Vercel, установленный Node.js или Python для использования не нужны. Интернет нужен для каталога, постеров и видео. Доступность видео зависит от источника и сети пользователя; приложение само по себе не снимает региональные ограничения.

## Установка

- macOS: открыть подходящий DMG (Apple Silicon либо Intel), перенести CineGram в «Программы».
- Windows x64: запустить EXE и пройти установку.
- Android 8+: установить APK. Это тестовая сборка с debug-подписью, предназначенная для личной проверки.

Mac и Windows пока без платных сертификатов подписи и нотариализации: система может показать предупреждение о неизвестном разработчике. Автоматического обновления пока нет. История и избранное хранятся на устройстве, между устройствами не синхронизируются.

## Устройство

Desktop использует Electron с изолированным интерфейсом и отдельным процессом Node.js для существующего Express API. Сервер слушает только 127.0.0.1:31847. Для парсинга используется существующий Cheerio fallback: Crawl4AI/Python в установщики не включён.

Android использует системный WebView и Java API на NanoHTTPD/OkHttp/Jsoup, слушающий только 127.0.0.1:31848. Каталог, поиск, карточки, поиск плееров, проксирование видео/HLS и общая защита от рекламы работают на телефоне. Источники парсятся напрямую; страницы с обязательной проверкой доступа могут быть недоступны. Нативных JavaScript-мостов и доступа WebView к файлам нет.

## Сборка

Нужен Node.js 24. Из корня репозитория:

```sh
npm ci --prefix apps
npm --prefix apps run desktop
npm --prefix apps run build:mac
npm --prefix apps run build:win
```

Для Android дополнительно нужны JDK 17 и Android SDK 35 с Build Tools 35.0.0. Указать путь SDK через ANDROID_HOME либо apps/android/local.properties (`sdk.dir=...`).

```sh
npm --prefix apps run prepare:android
cd apps/android
./gradlew assembleDebug testDebugUnitTest
```

На Windows используется gradlew.bat. Артефакты: apps/dist и apps/android/app/build/outputs/apk/debug. Generated AppConfig использует ключ метаданных из существующего server.js; он доступен внутри клиентской сборки. При широком распространении учитывайте общий лимит этого ключа.

Workflow «Build CineGram apps» запускается вручную в GitHub Actions и сохраняет сборки как artifacts. Он не публикует релизы. Для постоянного распространения Android нужен собственный сохранённый signing key: debug-ключи разных компьютеров/CI несовместимы для обновления поверх установленной версии.

## iOS и iPadOS

Локальный Swift-сервис и WKWebView для iOS/iPadOS 16+. [Установка через бесплатный Apple ID и сборка](ios/README.md). Команда подготовки ресурсов: `npm --prefix apps run prepare:ios`. Workflow **Build CineGram iOS** создаёт неподписанный IPA и запускает тесты в iPhone Simulator.
