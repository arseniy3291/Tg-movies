# CineGram для iPhone и iPad

Предварительная версия для iOS/iPadOS 16 и новее. Внутри — WKWebView и локальный Swift-сервис на 127.0.0.1:31849. Хостинг, Node.js и Python не нужны. Каталог и видео требуют интернета; доступность источников и региональные ограничения остаются зависимыми от сети пользователя.

## Бесплатная установка через Apple ID

IPA из GitHub — **неподписанный** файл. Прямая установка по ссылке на iPhone не сработает. Для установки на собственное устройство его нужно подписать своим Apple ID.

Вариант с Xcode:

1. Установить полный Xcode на Mac и добавить свой Apple Account в Xcode → Settings → Accounts.
2. Подготовить ресурсы и сгенерировать проект командами ниже, открыть `CineGram.xcodeproj`.
3. В Signing & Capabilities выбрать свою Personal Team. Если идентификатор занят, указать свой уникальный Bundle Identifier.
4. Подключить свой iPhone, выбрать его в Xcode и запустить приложение. Запросы доверия и Developer Mode на устройстве нужно подтвердить самостоятельно.

Бесплатная Personal Team выдаёт профиль на 7 дней: затем приложение потребуется переподписать и установить заново. Apple ограничивает число приложений и устройств. [Правила Apple](https://developer.apple.com/help/account/basics/about-your-developer-account).

Если используете AltStore Classic, можно импортировать IPA через его интерфейс установки приложений: [официальная инструкция](https://faq.altstore.io/altstore-classic/your-altstore). AltServer на Mac или Windows нужен для установки и обновления подписи; срок бесплатной подписи также 7 дней. Apple ID и пароль вводятся только вами в выбранном инструменте, их не нужно добавлять в код или GitHub Secrets.

Для друзей каждый подписывает приложение своим Apple ID. Сборка в GitHub Actions не требует Apple ID, сертификатов или платного аккаунта.

## Сборка проекта

Из корня репозитория (Node.js 24, Swift 6/Xcode 16 и новее):

```sh
npm ci --prefix apps
npm --prefix apps run prepare:ios
brew install xcodegen
xcodegen generate --spec apps/ios/project.yml
open apps/ios/CineGram.xcodeproj
```

Проверка локального API, переписывания плейлистов и HTML:

```sh
swift test --package-path apps/ios/Core
```

Workflow **Build CineGram iOS** собирает неподписанный IPA и проверяет запуск интерфейса в iPhone Simulator. Для создания подписанной версии используйте свою команду в Xcode. Для App Store/TestFlight нужны отдельные настройки распространения и участие в Apple Developer Program; эта сборка предназначена для личной проверки.

## Особенности

- История и избранное хранятся в WebKit на устройстве.
- API каталога использует тот же ключ метаданных, что существующий сервер; ключ включён в клиентскую сборку и имеет общий лимит запросов.
- HTML/CSS/HLS обрабатываются локально, видеосегменты передаются потоково с поддержкой Range. Размер буферизуемых текстовых ответов ограничен 8 МБ.
- Общая защита плееров от рекламы генерируется из существующего `providers/adblock.js`. Источники парсятся через SwiftSoup; Crawl4AI не включён.
- Камера, микрофон и нативный JavaScript-мост не используются. HTTP разрешён только для локального сервиса, внешние источники используют HTTPS.
- В фоне iOS может приостанавливать приложение. Фоновое воспроизведение, загрузки фильмов, AirPlay и автоматические обновления не входят в эту версию.
